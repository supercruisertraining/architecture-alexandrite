### Мотивация
- Выявлять узкие места в реальном времени – например, понять, почему MES тормозит при расчёте стоимости или почему RabbitMQ теряет сообщения.  
- Предотвращать сбои до их возникновения – мониторинг поможет заметить аномалии (например, рост времени ответа API) и принять меры до того, как клиенты начнут жаловаться.  
- Обосновывать оптимизации – данные из Grafana/Prometheus покажут, какие компоненты требуют доработки (например, высокую нагрузку на БД MES), а не действовать наугад.  
- Улучшать SLA для партнёров – если B2B-клиенты видят, что система стабильна (благодаря метрикам и алертам), это повысит доверие и сократит потери контрактов.  


### Выбор подхода к мониторингу
- Для очереди между MES и CRM я бы использовал подход "Четыре золотых сигнала"
- Для клиентского API MES предлагаю использовать подход RED, чтобы вовремя отслеживать неполадки,
и не доставлять неудобств клиентам
- Для CRM использовал бы подход USE, чтобы точно знать о нагрузке и общем состоянии системы

### Выбор метрик для мониторинга
- Number of dead-letter-exchange letters in RabbitMQ - метрика для очереди между MES и CRM. Ярлык - имя очереди
- Number of message in flight in RabbitMQ - метрика для очереди между MES и CRM. Ярлык - имя очереди
- Number of requests (RPS) for internet shop API - позволит отследить текущую нагрузку. Ярлык - код ответа.
- Number of requests (RPS) for CRM API - позволит отследить текущую нагрузку. Ярлык - код ответа.
- Number of requests (RPS) for MES API - позволит отследить текущую нагрузку. Ярлык - код ответа.
- Number of requests (RPS) per user for internet shop API - Позволит вычислять "спаммеров"
- Number of requests (RPS) per user for MES API - Позволит вычислять "спаммеров"
- CPU % - Нагрузка на CPU. Ярлык - адрес узла и имя сервиса
- Memory Utilisation - Нагрузка на CPU. Ярлык - адрес узла и имя сервиса
- Response time (latency) for shop API - Время отклика. Ярлык - адрес узла.
- Response time (latency) for CRM API - Время отклика. Ярлык - адрес узла.
- Response time (latency) for MES API - Время отклика. Ярлык - адрес узла.
- Number of orders per day - Метрика по количеству заказов  в день.
