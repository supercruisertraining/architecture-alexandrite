### Проблемные места
- Сложность масштабирования
- Долгая работа запросов на получение данных
- Отсутствие кэширования
- Возможность DDOS-атаки на сервис путем создания множества запросов на обработку 3d модели
- Плохая наблюдаемость системы

### Инициативы (по приоритету)
- Оптимизировать схему данных
- Добавить индексы для ускорения поиска
- Добавить кэширование
- Добавить ELK стэк для сбора и анализа логов
- Добавить распределенную трассировку
- Добавить минимальный временной интервал для идущих подряд запросов на обработку 3д модели


### Целевая архитектура через полгода
С учетом небольшой численности разработчиков и инженеров, 
в полугодовой период разумнее было бы работать над увеличением 
надежности и доступности системы.

Должен быть поднят ELK стэк, сервисы для распределенной трассировки. 
Основная часть архитектуры системы кардинально не поменяется через полгода, однако 
сервисам должна быть предоставлена возможность масштабирования
